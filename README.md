# EVA-CLM

### Единая Вычислительная Архитектура — когнитивная языковая модель без внимания

**VSA-память · кодовый словарь · единое τ-поле · групповые зеркала · обучение как непрерывный процесс**

```
      ┌──────────────────────────────────────────────────────┐
      │                       EVA-CLM                        │
      │     слово → КОД → суперпозиция → τ-иерархия → слово  │
      │                                                      │
      │   24 слоя · D=2560 · 32 эксперта · 212.3M весов      │
      │   словарь 65 536 при нуля параметрах эмбеддинга      │
      │   контекст без KV-кэша · динамика без magic-чисел    │
      └──────────────────────────────────────────────────────┘
```

> Исследовательская архитектура вокруг одного тезиса: **языковое моделирование —
> не умножение матриц внимания, а управляемая временем суперпозиция кодовых
> состояний.** Всё в этом документе — следствие этого тезиса.

## 1. Три допущения трансформера, которые здесь отрицаются

**Контекст — таблица пар (K, V).** Каждый шаг дописывает столбцы матрицы:
память линейна длине, стоимость внимания квадратична. Десятилетия индустрия
оптимизировала *следствие* (flash-attention, скользящие окна, KV-квантование),
не переспрашивая причину.

**Словарь — строки большой матрицы.** Эмбеддинги и голова стоят |V|·D: при
vocab 65 536 и D 2560 это ~335M параметров *только на перевод id ↔ вектор*.
Редкие токены недообучены, частые перекормлены, а градиент протекает через
softmax — функцию, ревнивую по определению: рост вероятности правильного
слова насильно принижает все остальные.

**Время — набор подобранных чисел.** Скорости EMA, температуры гейтов,
задержки разморозки, LR-decay по глубине — десятки констант без общей природы,
которые рассогласуются при любом росте модели.

EVA отрицает все три: **контекст — вектор суперпозиции, словарь — код, вся
динамика — функция одной величины τ.**

## 2. Три опоры EVA

**Память как суперпозиция (VSA).** Гиперполии (Plate, 1995): множество
объектов хранится одним вектором — суммой случайно повёрнутых элементов;
развязка корреляцией с элементом. O(1) на запись, ёмкость — порядок
размерности, деградация — плавная и «размытая», как у человека. В EVA этот
принцип несёт всю контекстную ветку: ни одной K×V таблицы в модели нет.

**Время как иерархия (τ-поле).** Кора мозга устроена так, что верхние зоны
меняются быстро, нижние — медленно. По глубине EVA идёт лестница постоянных
времени τ₁…τ₂₄, и из неё как из *единственной физической размерности*
выводятся скорости всех EMA, температуры гейтов, задержки созревания, профили
градиентного клипа и LR. Искривлять геометрию может один обучаемый параметр
на слой — всё остальное функции.

**Знание как код (sparse block codes).** Токен — не строка таблицы, а булев
код веса 6 из 32 бит; 65 536 слов живут в C(32,6) = 906 192 конфигурациях.
Вывод — не argmax по softmax, а 32 независимых вопроса «бит активен?».
Градиент на ошибку собирается побитно: модель учится *сборке ответа*, а не
конкуренции вероятностей. Цена словаря по параметрам — ноль.

Опоры перемножаются, а не сосуществуют: кодовое пространство — общий язык
для связывания, кэшей и головы; τ решает, где и как быстро эти коды имеют
право перезаписываться.

## 3. Карта модели

```
 токен id
    ▼
 Эмбеддинг: код → плотный микс → базис ⊕ RoPE          0 параметров от vocab
    ▼
 UCL (концепты-прототипы) + Банки L1/L2 (фраза/период)  контекст до стека
    ▼
 ×24  EVABlock:  conv → bind → VSA-память(4 темпа)
                 → mirror(32 эксперта) → спектр → GroupedMLP
      поперёк: SemanticBridge (глубина) · intent-шина (время)
      вглубь:  лестница τₗ · зрелость Mₗ · переменная точность
    ▼
 Logit Cache: 32 прошлых окна, кодовая проекция
    ▼
 SigmoidCodedHead: 32 бита + factorized branch
    ▼
 CE по каждой позиции + aux-симфония → спектрально-выровненный градиент
```

Поток не «слева вверх»: мост и intent носят сигналы и вниз (top-down),
память и кэш — поперёк времени, зрелость — поперёк глубины.

## 4. Слово как код, а не как строка

Каждому id сопоставлен детерминированный блок-код (инкрементальный отбор по
растущему хешу — дискретизация без обучения):

```
c ∈ {0,1}³²,  ‖c‖₀ = 6
z = σ(2 · M c)          M — фиксированная ортогональная матрица 32×32
e = z ⊗ B               B — базис сегментов; сегменты 1:1 с экспертами зеркал
e ← RoPE(e)             θ = 1e6, вращение по позиции
```

Плотный микс `z` превращает разреженный код в «запах» слова: похожие коды
автоматически дают близкие векторы, а пересечения бит между любыми парами слов
имеют *заданное* статистическое распределение — ровно то, что делает
гиперполию хорошо обусловленной. Отсюда: стоимость словаря — ноль, обобщение —
через пересечения кодов (два слова с двумя общими битами уже делят геометрию;
редкие слова не «недообученные строки», а комбинации выученных бит), и одна
решётка кодов служит всем интерфейсам модели сразу — привязке, кэшу, голове.

## 5. Bind: связывание, сохраняющее норму

Два базовых оператора VSA в модели — не групповое умножение на кругу, а
вложение в комплексную спираль с управляемой круткой:

```
u, v = сплит(h)                                    пары координат D → K
θₛ  = ωₛ · freq_scale · RMSNorm(Wp·h) + βₛ         обучаемые частоты и фазы
u'  = u·cos θₛ − v·sin θₛ ,   v' = u·sin θₛ + v·cos θₛ
bind = Σₛ Wₒ·(u'ₛ ⊙ v'ₛ)                           суперпозиция масштабов спиралей
```

Поворот — изометрия: ‖(u′,v′)‖ = ‖(u,v)‖. **Градиент не домножается на
случайную матрицу 24 раза подряд** — он проходит через вращение, сохраняя
норму: глубокий стек жив без танцевальных костылей вокруг нормализаций.

Второй принцип — **когерентность фаз**: величина |Σₛ e^{iθₛ}|/(S·d) заметна
только там, где спирали складываются в фазе. Состояние с подходящей
«частотной подписью» усиливает само себя в потоке; чужие фазы взаимно
глушатся. Селективность вырастает из физики, а не из жёсткого top-k.

## 6. VSA-память: четыре темпа понимания

Каждый слой держит четыре рекуррентных регистра с постоянными, привязанными
к τ слоя:

```
τ_s(l) = base_s · (τ_l / τ_mid),        base = 1, 4, 16, 64

decayₜ = clip( e^{−1/τ_s} · σ(hₜ·w_d + b_d), 0.01, 1 )
gateₜ  = softplus( hₜ·w_i + b_i + γ·‖hₜ − p̂ₜ‖ )
memₜ   = decayₜ ⊙ memₜ₋₁ + gateₜ · hₜ
```

* Быстрый регистр держит синтаксис фразы, медленный — тему документа.
* Множитель `σ(h·w_d)` делает забывание **контекстным**: на границе мысли
  регистр открывается шире.
* Член с ошибкой предсказания — примитив удивления: неожиданное записывается
  сильнее. Память здесь — функция несоответствия ожиданию (предиктивная
  обработка в чистом виде), а не буфер «последнего».
* Чтение — гибрид адресности и мягкости: `σ(scores)·(1 + softmax(scores/τ))`.

Рекурсия считается точным chunked prefix-scan'ом (fp64-кумулянты): параллельно
на обучении, O(1) памяти на инференсе. Никаких K×V — снова следствие опоры 1.

## 7. Cognitive Mirror: слой как совет экспертов

D=2560 разрезан на G=32 сегмента-эксперта. Каждый ведёт буфер из k эталонов
(staircase: 8 у поверхностных слоёв до 32 у глубоких) и судит о своём праве
говорить по пяти сигналам:

```
t — темп-согласие с регистром      p — точность предсказания следующего шага
s — гладкость (EMA с собой-вчера)  y — симметрия связки с парным сегментом
h — helpfulness: вклад в движение h против общего
```

```
gₑ  = σ( w·|Δₑ| + b + grad_mod + contradictions + meta_trust )
выход слоя по зеркалу = Σₑ gₑ · readₑ(bufferₑ)
```

Это MoE с **самооценкой по факту, а не по роутеру**: эксперта повышает его
предсказательная история, понижает — противоречие стволу и стагнация;
`meta_trust` даёт уверенно-непохожему эксперту право голоса выше своего
среднего (антихрупкость совета).

У каждого эксперта — **приватная память**, записываемая только из зрелого состояния
(`conf = σ(−‖Δ‖)`): опыт консолидируется посегментно, как миелинизация.
Чтение точного буфера включает переменная точность: STE-гейт
`precision = σ(gate(h))`, обучаемый сквозь CE — слой сам выбирает, где
достаточно грубого регистра, а где нужен точный след.

## 8. Спектр и GroupedMLP

**Спектральная ветвь**: сегменты h через фиксированный DCT-базис с
по-частотным множителем `λₖ` (обучаемый, модулируется τ-лестницей) — слой
решает, сколько высокочастотной (локальной) и низкочастотной (тематической)
структуры пропустить дальше. Осцилляторная настройка без осцилляторов.

**GroupedMLP** — SwiGLU ×32 группы ×4 расширение, но не слепой FFN: его
ворота спрашивают совет у зеркала и моста:

```
mod = σ(a + b·mirror) · usefulness
glu = σ(gain)·σ(Wg·f)·σ(Wv·f)                 живой смысловой гейт
out = Σ_f SwiGLU_f(x)·(1 + β·(2·glu−1))       при τ-якоре 1.5·σ на init
```

В EVA MLP — исполнитель, согласованный с памятью, а не «ещё один перцептрон».

## 9. SemanticBridge: модель, которая слышит себя

Стек блоков обычно передаёт только *результат* слоя, теряя его *намерение*.
Bridge вводит сквозной канал глубины:

```
sₗ = probeₗ(hₗ)                            семантический «выдох» слоя (256-мерный)
инъекция: hₗ₊₁ += tanh(c)·Proj(streamₗ)    stream — смесь соседей по глубине,
                                            горизонт смешения = τ_norm(слой)
время:    bridge_stream ← EMA(sₗ)          персистентная нить между шагами
самообучение: aux = 1 − cos( sₗ[t] , Emb(tok[t+1]) )
```

Мост **обучается предсказывать эмбеддинг следующего слова из смыслового
выдоха текущей глубины**: если выдох действительно несёт смысл — он обязан
быть предиктивным. Это dense-супервизор на каждую слой (~2M параметров на
связь целиком) и канал, которым смысл перетекает *мимо* остаточного стека:
резонанс глубины, не доступный градиентному конвейеру.

## 10. Intent-шина: нить внимания без окна

Модели нужно не только «что было», но и «о чём я сейчас». Intent-шина —
восходяще-нисходящий поток намерений, живущий в темпе своего слоя:

```
freshₗ    = σ(probe(hₗ))                             локальное намерение
carriedₗ  = aₗ·carriedₗ(t−1) + (1−aₗ)·freshₗ(t)      aₗ = 1 − 1/τₗ
bus       = fresh + carried        top-down:  gate_logits += salience·w_sal
```

Быстрые слои обновляют намерение почти на каждом шаге; медленные — «едят
слона», удерживая сквозную цель через сотни шагов. Это второй неоконченный
канал модели (первый — VSA-память): **размытое понимание + направленная
нить** — те две вещи, которые attention заменяет квадратичной стоимостью.

## 11. Концепты: UCL и банки L1/L2

**Unified Concept Layer** — глобальный слой из S=8 прототипов-концептов,
живущий сразу за эмбеддингом:

```
d = min_c ‖e − c‖ · новизна-порог (обучаемый разрыв)
рождение: уверенный + зрелый + новый паттерн становится прототипом
запись:   через index_copy — дифференцируемо, концепты обучаются CE-путём
чтение:   soft-attention по прототипам → модуляция всего стека ниже
```

Концепт умирает, если не востребован дольше своего τ-горизонта. UCL пишется и
на инференсе (§21) — «субъект, который узнаёт новое, не переставая говорить».

Под ним два буфера плавного распада:

| буфер | горизонт | запись |
|---|---|---|
| L1 | последние 3 предложения | на границе фразы |
| L2 | 32 обучаемых слота «периода» | по зрелости слоя ≥ θ |

Чтение — до стека: каждый слой начинает не с нуля, а с ощущения контекста.

## 12. Logit Cache: прошлое в кодовом пространстве

Стек живёт окнами по 256, понимание требует прошлого. Кэш держит **32
последних окна** и даёт стеку спросить у них:

```
запись:  h детачится; его k,v кодируются ОДНАЖДЫ при записи
         (k = k_norm(k_proj(h))) — память как записанный код, а не пересчёт

спрос:   q = Q(нынешнее окно) по 32 записанным (k,v) + живой хвост
вплёт:   h' = h + σ(gate(h)) · attn_out
```

* **Write-time encoding** — стоимость шага O(seq), не O(32·seq): прошлые окна
  закодированы весами того момента, когда были записаны, — как и положено памяти.
* **Кодовое пространство вместо словарного** (инференс): логиты 65 536-мерного
  поля сжимаются в *родной язык модели* — per-bit evidence кодовой головы:

```
profile = tanh(logits/10) · codesᵀ / S        V→32, 0 параметров
все карты — 32×D вместо 3×V×D:  −500M «роста»
```

* **Инициализация = тождество:** гейт стартует с σ(−10) ≈ 0 — модель начинает
  с «прошлое не нужно» и **покупает память только если CE докажет её
  полезность**. 43× экономия против KV-кэша на 1M токенов (≈5.5GB против 240GB).
* Scheduled sampling (5%) приучает трейн-контур к inference-представлениям;
  очистка на границах документов и eval.

## 13. SigmoidCodedHead: ответ без softmax

Голова задаёт 32 независимых вопроса «активен ли бит?» и собирает слово:

```
zₖ = ⟨hₖ, readoutₖ⟩/T + b_bit + b_tok       двойной bias: бит и токен — разные смещения
logit(w) = Σₖ codes[w]ₖ·zₖ − base          свёрточный скор по пересечению кода с битами
NLL(w*)  = Σ_{k∈w*} −log σ(zₖ) + Σ_{k∉w*} −log(1−σ(zₖ))     Бернулли по каждому биту
```

Почему это другая физика, а не «softmax на минималках»:

* **Градиент не ревнив.** Ошибка в трёх битах — штраф по трём битам,
  остальные 29 не трогаются. Softmax неверным ответом *обязательно* ломает
  вероятности всех правильных; здесь ошибка частична — частичен и ремонт.
  Это прямой ответ на хвост редких слов словаря.
* **Неопределённость lossless**: σₖ = 0.5 по всем битам — не «равномерно по
  65 536», а честное «биты не решены»; из неё читаются целые множества
  слов-кандидатов по пересечению кодов.
* **Factorized branch** — вторая декомпозиция той же цели: предсказание битов
  по подпространству сегментов; `CE + branch` обучают код надёжнее одного CE.
* NLL снимается по **каждой** позиции окна — плотность сигнала максимальна.

## 14. Рассуждение в скрытом пространстве

До головы — петля, где модель думает в том же D=2560, не тратя токены:

```
для r = 1…R(t):                               R адаптивно: средний гейт < 0.5 → выход
    a = sigmoid-attention(q(h), буфер витков)  множество тем, не одна
    h ← h + tanh(g_r)·read(a)                 g_r ∈ [−1,1]: отрицательный = антизнание
                                               («эта ветка прошлого — ложь, вычти»)
ramp: сила петли → 1 − exp(−t/1000)           рассуждение входит в силу постепенно
```

Буфер витков — сам VSA-регистр (O(1)), а **Triad** на инференсе даёт рассудку
право переспросить ствол целиком при низкой уверенности (`conf < θ` → второй
проход, консервативный бленд 0.5/0.5) — без единого нового параметра.
Рассуждение цепочками токенов — это внешняя костыльная версия того же; здесь
оно внутреннее и в своей валюте.

---

## 15. Зрелость: когда слой имеет право голоса

Слои включаются не расписанием, а созреванием:

```
Mₗ(t) = max( σ((t − T₀ − α(1−τ_normₗ)·T_задержки)/Δ) ,  готовность_моста(ℓ) )
```

Право писать память, модулировать MLP и впрыскивать мост масштабируется Mₗ;
замороженный слой не молчит — его базовый гейт ≈ 0.667 оставляет щель для
обучающего сигнала. Глубокие слои открываются **первыми** (инверсия
bottom-up): компетентность сквозного канала важнее счётчика шагов. Возраст —
время; зрелость — право; τ — связь между ними.

---

## 16. τ-поле: единица измерения архитектуры

```
τₗ = exp( ln τ_min + ln(τ_max/τ_min)·((l−1)/(L−1)·(1+0.3·devₗ) + 0.05) )
```

Лестница от ~4 шагов (поверхность, синтаксис) до ~512 (глубина, тема) — и
**все** темпоральные константы модели выводятся из неё:

| Что | Формула |
|---|---|
| EMA-горизонты (VSA, intent, bridge) | `α = 1 − 1/τₗ` |
| задержка созревания слоя | `T₀ + (1−τ_norm)·T_delay` |
| температуры гейтов | геометрическая интерполяция τ_min^g…τ_max^g |
| целевая скорость записи памяти | `i_target = min(1, c/τ)` |
| LR по глубине | `(τₗ/τ_ref)^(−γ)` |
| сила клипа AGC | `c·(τ_ref/τₗ)^γ` |
| частоты спирали bind | `(τ_min/τ_max)^(τ_norm·η)` |
| спектральное демпфирование | `cos(π·τ_norm/2)` |
| бюджеты рассуждения, пороги концептов, веса λ… | см. U1–U10 |

Ни одной независимой константы. Хочешь замедлить модель — подними лестницу,
и четырнадцать механизмов сдвинутся **вместе**, как стрелки связанных часов.
Искажение геометрии — один обучаемый вектор `devₗ`. Это и есть «единая
вычислительная архитектура»: одна размерность времени вместо набора чисел —
как метр в СИ.

---

## 17. Обучение: из чего состоит сигнал

Главная потеря — побитовый Бернулли-NLL кода правильного слова (§13) по каждой
позиции. Вокруг — aux-симфония, и у каждого голоса τ-обоснование:

| сигнал | что требует |
|---|---|
| `pred` | регистр должен предсказывать следующий шаг |
| `bridge_conn` | смысл слоя должен предсказывать следующее слово |
| `gate_l1` | гейты зеркал — разреженность |
| `diversity / div / decorr` | сегменты не должны схлопываться в близнецов |
| `reinforce` | эксперта нельзя повышать без предсказательной пользы |
| `balance` | ни один сегмент не узурпирует поток |
| `gradalign` | aux-градиент должен учить гейты, а не мешать CE |
| `novelty / signal_ent / repulse / …` | гигиена суперпозиции |

Aux-сигналы возвращаются из модели **сырыми** — ни одного ручного веса λᵢ.
Всё, что влияет, видно в геометрии градиента; всё, что не влияет, — телеметрия
стража, и она так и помечена.

---

## 18. Балансировка градиентов без магических весов

```
g_aux ← g_aux · max(cos(g_CE, g_aux), 0) · ‖g_CE‖ / ‖g_aux‖
```

Aux-градиент проецируется на CE и **конструктивно ограничен длиной ‖g_CE‖**:
согласованный — проходит целиком, ортогональный — молчит, противный — отсечён.
Доверие к aux-потере измеряется не ламбдой из тетрадки, а косинусом в этой
самой точке пространства градиентов — то есть самими данными.

## 19. Оптимизайзер и планировщик, синхронные модели

**EVAAdamW** — Adam с добавками и *проверенным эталоном* (в чистом режиме
bit-identical torch-AdamW — чтобы сравнивать нечестное с нечестным нельзя):

* **cautious mask**: шаг применяется только когда знак совпал с текущим
  градиентом — экспоненциальная память не тащит назад;
* **radial-подавление (AdamP-null-band δ=2/√D)**: из шага снимается компонента,
  ведущая к вырождению сегментных геометрий;
* **медленные EMA движения весов** — опциональная «подкорка», накапливающая
  траекторию в выпуклом u-пространстве.

**MirrorLR** читает статистику самой модели вместо календаря:

```
mult = ³√(var_ratio · α_ratio · gate_ratio) · mag · loss_factor
```

Движение зеркальных компонент вверх → LR вниз (модель бежит, не подталкивай);
затишье → вверх (можно смелее); улучшение val ×1.05, регресс ×0.5; после
дивергенции — **re-warmup** (прогреть заново), а не «уменьшить вдвое».
Группы LR собраны той же τ-лестницей: глубина × роль × WD — единственные оси.

## 20. Дисциплина длинного прогона

Многодневное обучение на арендованном GPU имеет смысл, только если цифрам
можно верить. Что для этого сделано:

**Один чекпоинт — всё состояние.** `best.pt` пишется при улучшении val и
хранит весь прогон: веса, оптимизайзер (восстановление по именам переживает
смену архитектуры), планировщик, историю val, **базлайны стража**, курсор
данных и RNG-потоки. Перезапуск продолжает марафон, а не начинает новый.

**Страж вместо порогов.** Откат по относительному правилу на пяти сигналах
(CE, разнообразие, активация гейтов, соотношение MLP, информированность):

```
viol = value > slow_EMA·(1+margin)  И  value ≥ healthy-band floor
```

Быстрая EMA видит всплеск, медленная (×10 длиннее) не даёт новому плато
«привыкнуть» к деградации; нечисловой CE — тревога безусловно. Решением D6
страж лишён права на само-починку: он только сигналит, прогон останавливается;
дальше — человек и чистый best.pt. Дискретный аварийный исполнитель дважды
становился причиной фатальных инцидентов, но не лечил коренных причин;
непрерывное регулирование осталось адаптивному слою: MirrorLR, AGC,
maturation, soft-veto M14b.

**Валидация, которую нельзя испортить.** Holdout — 3 файла корпуса на уровне
файлов, навсегда исключённые из обучения; вокруг eval изолируются рабочие
буферы, концепты и кэш — валидационные документы не оставляют следа в памяти
модели. Окна ротируются по границам документов с полным сбросом потоков.

**Ни одного мёртвого механизма.** Автотест ищет параметры с нулевым
градиентом вне явного белого списка с обоснованиями. В системе из ~15
подмеханизмов «молча не работает» — главный способ самообмана; против него
стоит страж.

---

## 21. Инференс как часть обучения

EVA не разделяет «фазу жизни» и «фазу службы»:

* концепты UCL **рождаются из инференса** — уверенный, зрелый и новый паттерн
  записывается без всякого backward;
* регистры и кэш стриминговые по построению: генерация любой длины стоит
  O(1) на шаг;
* logit-кэш живёт обеими половинами dual-mode (h на трейне, кодовый профиль
  на инференсе), scheduled sampling сшивает представления;
* сгенерированные токены возвращаются в модель как настоящие — «речь»
  консолидируется в опыт.

## 22. Цена: против трансформера по всем осям

Сравнение при равной ёмкости (D=2560, 24 слоя, |V|=65 536):

| Ось | Трансформер | EVA-CLM |
|---|---|---|
| Память контекста на шаг | KV-кэш O(L·D) | регистры + окна O(D) |
| FLOPs контекста | O(L²·D); обход — окнами | линейный скан + оконный кэш |
| Параметры словаря | ≈ 335M | **0** (буфер кодов) |
| Вывод | softmax, ревнивая конкуренция | 32 независимых бита |
| Константы динамики | десятки ручных | 0: функции τ (1 сдвиг/слой) |
| Рассуждение | цепочки токенов снаружи | петля в скрытом пространстве внутри |
| Обучение на инференсе | нет | концепты, консолидация |
| Живой прогон | — | fp32, L4 22.5GB: seq 256 · 15.3GB · ~70 tok/s |

Экономия — не «оптимизация трансформера», а следствие опор: матриц внимания
нет не потому, что их удешевили, а потому что контекст — суперпозиция.

## 23. Что здесь доказывается

Ставка формулируется как эксперимент, а не как манифест:

1. **Инструментальный уровень** — механизмы живы и честны: градиенты доходят
   (детектор мёртвых параметров), численные схемы точны (fp64-эталоны сканов),
   оптимизайзер верифицирован до побитового совпадения с эталоном, длинный
   прогон resume-безопасен и наблюдаем. *Проверено.*
2. **Идейный уровень** — **быстрее ли EVA учится на токен**, чем
   трансформер равных параметров и вычислений? Отвечает цикл ~38M токенов на
   L4 против matched-vanilla при том же бюджете. *Идёт.*
3. **Механизменный уровень** — kill-tests: обнуление каждого U-механизма с
   измерением потери; красота формулы ещё не аргумент нужности. *В плане.*
4. **Уровень существования** — то, что недоступно baseline на этом бюджете:
   retrieval за пределы окна через банки и кэш. *В плане.*

Нулевой разрыв в пункте 2 — результат, а не поражение: система спроектирована
говорить правду.

## Эпилог

EVA-CLM — ставка на то, что язык моделируется **без квадратичного внимания,
без словарных матриц и без десятков подобранных констант**: суперпозицией
— хранить, τ-полем — выводить временем, кодом — говорить. Архитектура
построена так, чтобы её можно было опровергнуть. Это самое ценное, что в неё
вложено.

**Лицензия:** экспериментально. API меняется, миграция чекпоинтов явная и
поимённая. Опровержения и kill-tests приветствуются больше аплодисментов.
