# Синтез: четыре внешних проекта — архитектуры и корреляционные методы

Источник: отчёты агентов (2026-09-18): `EXT_EVA-Ai_REPORT.md`, `EXT_FCF_REPORT.md`,
`EXT_FCP_REPORT.md`, `EXT_WideBind_REPORT.md`. Цель: что переносимо в EVA-CLM,
что отвергнуть, какие грабли подтверждают нашу дисциплину.

## 1. Что это за проекты (по отчётам)

| проект | суть | состояние |
|---|---|---|
| **WideBind** (внутр. имя EVA) | прямой предшественник EVA-CLM: VSA, нормосохраняющий bind, зеркало 32 экспертов, τ-поле, гибридная голова | 825 коммитов, 56 тестов; в репо best.pt = свежий рестарт 233/25.9; корпус отсутствует |
| **EVA-Ai** | приложение (CoreBrain+EventBus+GUI, 518 файлов/144k строк) + копипаста FCP-ветки | FCPipeline ни разу не поднялся; RAM 98–100%; настоящих тестов/CI нет |
| **FCF** (Fractal Cognitive Field) | no-backprop VSA-поле: STDP + контрастив + морфемная гармонизация | прогон остановлен на 270k/1M строк; 390 тестов; PPL-артефактов нет |
| **FCP** (= MemBind) | рекуррентная LM: ковариационная память + bilinear bind + спектр | research-прототип; 98 GB данных; крупный прогон не завершён |

## 2. Корреляционный канон (что сходится у нескольких проектов)

1. **Ковариационная память 2-го порядка** (EVA-Ai, FCP):
   `M[t] = d·M[t−1] + i·k⊗k`, чтение `q·M·W_read`, parallel prefix-scan,
   multi-head, feedback `v_enh = v + mem·W_mem2v`.
   Замер FCP: PPL 466 против 793/688, 3.7× скорость. Это ровно тот пробел,
   который зафиксирован у нас («VSA-суперпозиция, а не ковариационная матрица»).
2. **Bind-семейство** (WideBind, FCF): комплексные вращения (изометрия) +
   hybrid HRR/elementwise с α-рампом 0.3→0.7 + когерентность фаз |Z|,
   усиливающая запись; spiral_bundle со знаковыми весами (FCF).
3. **Единый гейт** `σ(l)·(1+softmax(l/τ))` (WideBind) — сквозной для головы,
   памяти, концептов; у нас уже в голове — эталон одной реализации.
4. **Контрастив с hard-negative mining** (FCF): cosine top-2000 + cooc/field
   маски + homeostatic boost + антоним-репел ×(−2). Прямой кандидат для
   голодающего контрастива моста (bridge_conn ≈ шанс).
5. **Collocation/PMI-prior** (FCF): L2-матрица cid-ключей с λ-prior — независимый
   prior-сигнал; кандидат в aux-симфонию / token_bias-контур.
6. **Спектральные операторы** (EVA-Ai, FCP): DCT + λ-sliding на корнях Фибоначчи
   (0 параметров), frozen-мультимасштабные головы τ=[3,12,49,200] + std-mirror.
7. **Prefix-scan log-space** (WideBind, FCP, EVA-Ai) — у нас уже есть
   (core/vsa_utils.py), подтверждён как правильный примитив.
8. **Фантом-лайфцикл EVA-Ai** — уже перенесён (0.75/0.25); добрать:
   cycles_before_stable=5, +0.25 за внешнее подтверждение, классификатор
   ambiguous/emerging, аудит-лог.
9. **Римановы tangent-регуляризаторы** (FCF): centroid pull / lateral inhibition
   / global repel — без новых параметров; кандидат для branch/diversity.
10. **ZeckendorfReadout** (FCP): точная нормированная P(i|h)=Π_k P(b_k|h,state) —
    родственник нашей бит-головы; кандидат в A/B против σ×softmax.

## 3. Грабли (сходится у всех — и подтверждает нашу дисциплину)

- **Doc drift**: README обещает то, чего нет в коде (WideBind: FFT-HRR,
  readiness-гейт, Projector; FCF: 768D vs 256D, «391 тест» vs 390+1).
- **Мёртвые механизмы, которые «измеряются»**: `mod_scale_mlp` мёртв, но
  именно его меряет весь WAKE-анализ WideBind; `pred`-лосс мёртв (detached).
- **Тихие fallback'и**: `except: fallback` скрывает всегда-падающие модули
  (EVA-Ai: TrainableGate/CrossAttention).
- **Фантомные API**: функции с рандомными/фиктивными данными выглядят живыми
  (EVA-Ai: retrieve_similar, фиктивные эмбеддинги hash+np.random).
- **Потеря состояния**: save удаляет предыдущий чекпоинт (FCP); корпус/данные
  отсутствуют (WideBind, EVA-Ai); pickle-чекпоинты.
- **Несовместимые определения одного понятия**: два перехода в одном
  TransitionManifold (FCF); hash-ключи от обучаемых векторов.
- **Ноль CI**: настоящих тестов/CI нет ни в одном (кроме FCF-390 и WideBind-56).

Наши контракты (git-hash+cfg_fp-пин, liveness-census, τlint, доки-журналы,
pre-registered A/B) — прямой ответ на эти классы; предшественники умерли
именно от них.

## 4. Приоритет переноса в EVA-CLM (предложение)

1. **Ковариационная память** (EVA-Ai/FCP) — как отдельная ветвь/банк,
   A/B против текущей VSA-памяти (замер FCP — 466 vs 793).
2. **Hard-negative mining для контрастива моста** (FCF) — лечит голодание
   (bridge_conn ≈ шанс) без форса: даёт цели градиент.
3. **Фантом-добор из EVA-Ai** (cycles_before_stable, внешнее подтверждение,
   классификатор) — малый риск, прямой апгрейд текущего лайфцикла.
4. **Римановы регуляризаторы** (FCF) — в diversity/branch (A/B).
5. **ZeckendorfReadout** (FCP) — A/B против головы.
6. **Collocation/PMI-prior** (FCF) — исследовать как независимый сигнал.

Не переносить: no-backprop парадигму (FCF), maturation-формулу WideBind,
Intent Bus/SemanticBridge как есть, manifold-beams, gradalign, весь мёртвый
код (spectrum_gate, amp_optim, curriculum, Projector), pickle-чекпоинты.
