## 2. Математика

### 2.1 Валюта ΔCE: три варианта

Обозначения: `ℓ(θ;x,y) = −log p_θ(y|x)`; `ΔCE = E[ℓ₀ − ℓ₁]` (положительно = канал помогает).

**(а) Paired ablation.** `d_i = ℓ₀,i − ℓ₁,i`, `Δ̂ = (1/N)Σd_i`, `SE = σ_d/√N`. Несмещён (маргинальный эффект при текущих θ). Цена: второй forward ≈ `2NT` = 6.5e11 FLOPs (~1/3 шага fwd+bwd); память — `snapshot_runtime_buffers` (копия всех буферов, включая logit-cache ≈293 МБ). Дисперсия: `σ_d∈[0.05,0.5]`, N=448 → `SE∈[0.0024,0.024]` нат/токен; для 2σ-детекции Δ=0.01 нужно `n∈[0.23,23]` батчей. **σ_d не измерена** — первый фальсификатор.

**(б) Proxy: first-order gradient currency.**
1. Бесплатная валюта через градиент (backward уже посчитан): для слота UCL `g_v[s] = ∂ℓ/∂vals_eff[s]`, `g_k[s] = ∂ℓ/∂keys_eff[s]`; при апдейте `Δv_s, Δk_s`: `c_s = −(⟨g_v[s], Δv_s⟩ + ⟨g_k[s], Δk_s⟩)` — предсказанное первым порядком снижение CE. Память ~90 КБ, FLOPs 0.
2. Matching pursuit для кандидата (фантомы — no_grad-буферы, градиента у направлений нет). `g_u = ∂ℓ/∂u` (K=64), `mix` — (K,Kp). Для слота `c_s = Σ_n p_{n,s}⟨g_{u,n}, mix[:,s]⟩`; для нового направления d: `p_d = tanh(e_l·d)`; лучшая колонка `m* = −g_uᵀp_d/‖g_uᵀp_d‖`, выигрыш `ĉ_d = ‖Σ_n p_{d,n} g_{u,n}‖₂` — greedy-выбор атома по корреляции с неиспользованным градиентом CE (OMP на линейном readout `u += pM`). Цена O(N·K) ≈ 29 тыс. MAC.
3. R²-прирост линейного предиктора: `ΔR² = (2⟨r, Bφ⟩ − ‖Bφ‖²)/‖h_{t+1}−mean‖²` — требует онлайн-ковариаций в sketch-пространстве (`O(N·d·D)` ≈ 7.3e7 MAC/шаг, 0.01% форварда); измеряет полезность для pred-лосса зеркала, не для CE.

**(в) IB / вариационная граница.** `log p(y|x) ≥ E_q[log p_θ(y|h(x,z))] − KL(q(z|x)‖p(z))`; IB: `L = E[CE] + β·I(z;x)`, `I(z;x) ≤ E[KL(q(z|x)‖p(z))]`. При S=8 `KL ≤ ln8 ≈ 2.08` нат/позиция (≤930 нат/батч) против полезного сигнала 0.01 нат/токен → нужно `β ≲ 1e-3`. IB не даёт per-slot валюты без контрфактуала — только стоимость ёмкости. Цена O(B·L·S).

**Рекомендация:** первичный — (б1)+(б2) (бесплатно, нулевая задержка); аудит/калибровка — (а) с каденсом 250 (0.13% времени шага, 0.3-0.4 ГБ пика; на A100 ок); (в) — только как принцип ёмкости.

### 2.2 Жизненный цикл по валюте

`κ_s` — EMA валюты: `κ_s ← (1−η)κ_s + η·c_s`, `η = 1 − 2^{−Δ/H}` (Δ=25, H=250 → η≈0.067).
- **Рождение**: `UCB(ĉ_d) = ĉ_d + z·SE(ĉ_d) > 0` устойчиво на k=3 независимых батчах И `novelty > gap`. Заменяет `birth_thresh` и снимает «рождение в каждый observe-вызов».
- **Подтверждение**: `κ_s > τ_conf` на k=3 подряд. `τ_conf ≈ 0.01-0.1` нат/ток (CE≈10.8, вклад 0.1-1%).
- **Архивация**: `UCB(κ_s) < 0` на окне W=200 ИЛИ нулевое использование (`attn_s≈0`) W шагов.
- Замена констант: `0.999 → η`; `0.05 → c_s`; `confirm=0.75 → τ_conf` (в натах); `archive=0.25 → UCB<0`.

**Взаимодействие с M62 (250 шагов = 112k токенов/чанк):** наблюдений при каденсе 25 — **10 за чанк** (≤320 позиций). Подтверждение при k=3 — 75 шагов = 0.3 чанка; при k=8 — 200 шагов < 250. То есть 250-шаговый интервал достаточен; связывающее ограничение — время жизни слота.

**Текущие числа:** phantom births≈1000 за ~6270 активных шагов ⇒ λ=0.159 рождений/шаг ⇒ ~4 рождения на observe ⇒ при 16 слотах **время жизни слота ≈ 16/0.159 ≈ 100 шагов**, а для confirm нужно 8 слияний с учётом decay 0.975/call (0.5→0.75: 8 наблюдений = 200 шагов). **200 > 100 — подтверждение структурно невозможно** (наблюдается confirmed 0-2). Более того, измеренный максимум conf = 0.5 = `conf_init` означает, что **ни один живой слот ни разу не слился** (одно слияние дало бы 0.5375) — `merge=0.7` на остатках D=2560 не достигается. UCL: births=307 ⇒ λ=0.049 ⇒ **жизнь слота ≈ 163 шага** (8/0.049) — тоже меньше чанка. И `concept_confidence` заморожен при рождении, поэтому links B/C фильтруют по **рождённому** значению. Мёртвая петля: link A требует confirmed≥0.75 (нет), link C — conf≥0.5 (max 0.600 ⇒ ≤1 направление).

**Вывод:** при текущем интервале 250 валютный lifecycle даст подтверждения только после починки эвикции; интервал можно оставить 250 (запас 2.5×), либо снизить каденс наблюдения до 10-15 (цена observe ничтожна: O(32·D)).

### 2.3 UCL self-closure: градиент и (не)оптимальность

**Градиент.** `out = read·u_gate·c_gate·σ(w)·cap`, `cap = min(1, 0.25‖h‖/‖out‖)` (нормы detached → cap — константа шага). Тогда `∂ℓ/∂w = σ(w)(1−σ(w))·Σ_pos ⟨∂ℓ/∂h_out, read·u_gate·c_gate·cap⟩`.

**Почему закрылся за ~120 шагов.** Исторически init `read_scale=0.0` (σ=0.5) — коммит `82c3202`; при случайных vals и random out_proj read — шум. `V(σ)=E[CE(h+σR)] = V(0) + aσ + ½bσ²`, `a = E⟨∇ℓ,R⟩`, `b = E[RᵀHR] > 0` (CE выпукла по логитам, логиты локально аффинны по h). Для шума `a=0` ⇒ `σ* = 0`. SGD гонит σ→0; при σ=0.5 чувствительность максимальна (`σ'(0)=0.25`), 120 шагов при lr≈3e-4 достаточно для 0.5→0.018.

**Почему «снова закрылся» после floor — это не закрытие.** `scale = scale.clamp(min=_fl)` (`concept_layer.py:376-378`). При `σ(w) < _fl` clamp возвращает константу ⇒ **`∂scale/∂w = 0` ⇒ градиент в `read_scale` ровно ноль**. Init −4.0 (σ=0.018) < floor 0.1 ⇒ clamp связывает **с первого шага** ⇒ параметр заморожен на −4.0 все 5000 шагов. Измеренное после релиза `σ=0.0179` соответствует `w = logit(0.0179) ≈ −4.005` — это **значение init**, а не «повторное закрытие». M59-эксперимент не мог отличить «модель хочет закрыть» от «модель не может учиться, пока заморожена». (Проверяемо по чекпойнту: `concept_read_scale` в течение floor должен быть ровно `σ(−4.0)=0.017986`.)

**Оптимально ли?** Условно да: пока read не коррелирован с целью, `a≥0`, σ*=0. Динамически нет: при σ→0 градиент пути записи ∝ σ, write-проекции перестают учиться, концепты навсегда остаются шумом, `a` не может стать отрицательным — **самоподдерживающийся дедлок**.

**Floor vs валюта.** Floor — разомкнутый контур: `σ_t = max(σ_f, σ(w_t))` на `t<T`, стоимость `T·½bσ_f²` при нулевом сигнале, выгода — градиент записи ∝ σ_f (в 5.6× больше, чем при 0.018). Валюта — замкнутый контур, но при закрытом канале `a` **неизмерима** — нужно исследовать. Корректная формулировка — UCB: держать σ открытым, пока `UCB(a) = â + z·SE > 0`, и закрывать только при `UCB(a) < 0`. Floor — вырожденный UCB с фиксированным T. Правильный ответ: floor-субсидия **с градиентом сквозь неё** (репараметризация `σ = σ_min + (1−σ_min)·sigmoid(w')`) + релиз по валюте.

### 2.4 Reasoning: IB и гейтинг по измерению

Пусть `z ∈ {0,1}^K` — ворота шагов, `q_φ(z|h) = Π Bernoulli(a_i)`, `h_z = h + s·Σ_i z_i r_i`. Per-step правило (greedy): **включать шаг i, если `Δ_i = E[log p(y|h_{≤i}) − log p(y|h_{<i})] > β·ΔKL_i`.** При обучении `Δ_i` измерима (есть y; голова уже вызывается на каждом шаге); при инференсе — без y, валюта заменяется на **энтропию** `ΔH_i = H(p(h_{<i})) − H(p(h_{≤i}))` (энтропия уже считается в `_knowledge_signal`).

Текущий код — эвристическая версия: `w_soft = σ(20·Δconf)`, но (1) max-prob вместо энтропии/CE, (2) скаляр по батчу, (3) под `no_grad`, (4) гейт 0 несменяем (STE только i>0), (5) K=4, а не 8.

Стоимость: `_knowledge_signal` — полный forward головы (3.8e9 FLOPs, 0.6% форварда), `_last_conf` — 8.4M MAC; переход «conf→энтропия» бесплатен. Риски: Гудхарт (энтропия падает и при уверенно-неверном ответе — в training только CE); нестационарность (EMA ≥100 шагов); главное — **при CE 10.8 против униграммы 7.48 рассуждать не о чем**: неопределённость доминируется невыученными частотами. `gates=0` — правильное поведение.

## 4. Режимы отказа

1. **Хаотическая эвикция** (phantom): при 32 позициях и 16 слотах каждый неслившийся остаток рождает/эвиктит слот. Банк — не память, а снимок последних ≤16 остатков; подтверждение невозможно арифметически.
2. **Frozen confidence** (UCL): `concept_confidence` пишется один раз; links B/C фильтруют по нему.
3. **Заморозка floor'ом**: clamp(min) даёт ровно нулевой градиент.
4. **Дедлок холодного старта**: закрытая σ ⇒ градиент записи ∝ σ ⇒ концепты не обучаются ⇒ a≥0 ⇒ σ остаётся закрытой.
5. **Goodhart валюты**: первый порядок по одному батчу поощряет шумовые признаки; лечение — UCB по k батчам + paired-ablation аудит.
6. **Goodhart reasoning**: энтропийная валюта поощряет sharpening без правильности; в training мерить CE.
7. **Reasoning ramp**: s=1e-3 при включении — вклад ~1e-3 от ‖h‖; STE+Adam может гнать логиты шумом до t~700; гейт 0 несменяем.
8. **Теле́метрия чанка**: комментарий config.py:478 и print ноутбука считали 27.5k ток/шаг — в 61× больше факта (исправлено).

## 7. Вердикты

1. **Валюта ΔCE — делать, но переформулировать.** Чистый ablate-and-measure как первичный сигнал — нет (FLOPs + σ_d-неопределённость). Правильная конструкция: бесплатная first-order валюта из backward + paired-ablation аудит каденсом 250. IB — принцип ёмкости, не per-event валюта.
2. **Lifecycle по валюте — делать, но сначала починить эвикцию.** Без этого валюта не имеет субстрата: слот живёт 100-163 шага при нужных 200+, подтверждение арифметически невозможно.
3. **Self-closure — переформулировать.** «Повторное закрытие» — артефакт `clamp(min)` с нулевым градиентом: параметр всё время был заморожен на init −4.0. Floor — не доказательство бесполезности UCL. Правильный ответ — репараметризованная шкала + релиз по UCB валюты.
4. **Reasoning — делать, но не сейчас.** Гейтинг формально верен, но при CE 10.8 против униграммы 7.48 узкое место — невыученные частоты; `gates=0` корректно.

**Неопределённости:** `σ_d` не измерена; births≈1000 — агрегат из брифа; точный шаг включения reasoning и стартовое `reasoning_enabled_step` не подтверждены чекпойнтом; «-4.0 за 120 шагов» относится к старому init 0.0 (коммит `82c3202`), не к текущему.
