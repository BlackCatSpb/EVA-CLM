## 1. Агент A — голова/readout

- **Полоса 64 направлений — не бутылочник**: 64 координаты несут сотни бит; ограничение — ориентация и обучение. Измерено: ∂CE/∂h **ровно** в span(readout) (остаток 0.0) — ствол получает кредит только вдоль 64 направлений; readout почти заморожен (std 0.1552 vs init 0.1581, −1.9% за 7315 шагов; LR=λ⁻²·6e-4=1.77e-4 + AdamP).
- **Код-канал сейчас вреден**: CE(code-only)=12.84 > CE(bias-only)=8.65 > uniform=11.09 (окно 224). Униграмма выучивается через token_bias (std 0.62 из нужных 1.67, наклон регрессии на лог-частоты 0.32, corr 0.84).
- **Многопроходная голова информационно пуста**: z2 = R(h+Q(z1)) = z1 + R·Q(z1) = F(z1) ⇒ I(Y;z2) ≤ I(Y;z1). Нужна вторая НЕЗАВИСИМАЯ матрица чтения, а не re-query. Риск self-confirmation как у SRL при обучаемом Q без cap.
- **RMS-норм u лечит несуществующую болезнь** (см. п.5 выше); при жёсткой нормировке теряется per-position острота (её несёт T).
- **Акцент мёртв**: |emph|≤0.05 при u std 0.8 (≤1.5%); λ=−1.25 — шум канала. Правильный фикс — per-bit g_k (64 параметра, forward-идентичен при init=−1.2495), иначе канал удалить.
- **Вердикты**: полоса — переформулировать (сначала F1-A/D: head-only тест + линейный оракул); многопроходность — не делать; RMS — не делать; акцент — per-bit или удалить.

## 2. Агент B — гейты/контроллеры (24 позиции)

- Инвентаризация: **7 измерений** (годы), **6 таймеров** (maturation ramp, lbg_tau, UCL floor/hard-skip, phantom decay, seq-curriculum, OOM-лестница), **5 инертных** (LBG, SRL, reasoning, wall при sat=0, lbg_tau), 3 обучаемых/предохранителя, 3 вне живого контура.
- **LBG — привод без нагрузки**: SpectrumGate считается, но поток берёт probe_layer(h.detach()) (stack.py:603); единственный потребитель lbg_diversity — на detached-clone, при =0 ключ не эмитится → log_tau без градиента. Плюс losses.py использует устаревшую инлайн-копию диагностик (diag[3]=0.5).
- **Шина доказательств**: 6 сигналов из уже существующих величин (pred-error, grad-SNR, effective rank, относительная новизна, var(log_scale), согласованность зеркал); отображения — квантильные (PIT) для гейтов безопасности, learned monotone только в CE-пути; лаг 1 шаг; safety-deadline вместо max(ramp,·).
- **Протокол фальсификации**: T1 сигнал двигает выход, T2 не функция step, T3 причинность (подмена старого сигнала), T5 живой градиент, T6 мёртвый канал. Миграция: сначала инструментация (0 риска), потом триаж мёртвых, phantom decay→по возрасту наблюдения, UCL floor→квантиль, maturation последним с rate-limit.

## 3. Агент C — концепты и reasoning

- **Валюта ΔCE**: чистый ablate-and-measure дорог (второй форвард + σ_d не измерена); рекомендуемая конструкция — **бесплатная first-order валюта из уже посчитанного backward** (c_s = −⟨g,Δ⟩ для UCL; matching-pursuit ĉ_d для фантомов) + paired-ablation аудит каденсом 250.
- **Lifecycle**: слот живёт 100–163 шага при нужных 200+ → подтверждение невозможно; `concept_confidence` заморожен при рождении (пишется один раз) — links B/C фильтруют по рождённому значению. Лечение: UCB-правила (birth при UCB(ĉ)>0 на k батчах, archive при UCB(κ)<0), decay 0.999→EMA-забывание доказательств, эвикция по min-κ.
- **Floor→репараметризация**: σ = σ_min + (1−σ_min)·sigmoid(w') — градиент жив у рельса; релиз по UCB валюты, не по часам.
- **Reasoning**: гейтинг «мысль обязана снижать неопределённость» формально верен (per-step ELBO/IB), но при CE 10.8 vs униграмма 7.48 рассуждать не о чем — gates=0 корректно. Перед включением: STE для гейта 0, замена max-prob на энтропию/CE, ramp по валюте.

## 4. Агент D — память

- Банк = **обучаемый per-forward bias**: чтение константно (cos≈1.0), W_k/W_v заморожены (@torch.no_grad), novelty_gate мёртв by construction, fusion[-1] zero-init ⇒ на старте градиенты всего read-пути ровно 0; mb_scale=−0.963 = tanh(−2.0), дрейф +0.0132 за 7315 шагов.
- **Предсказательный запрос (a/b/c) сам по себе не поможет** — адресовать нечего; сначала оживить запись (живой граф или self-supervised цель W_k(summary_t)≈W_k(h_{t+1})), нормировать q, пересмотреть шкалу score.
- Surprise-маршрутизация — не сейчас; ценность пока в логировании ν_l/pen/λ_lac. L3 (UCL) насыщение 8 слотов — норма, но ёмкость — предел.
- Потолок CE-выигрыша памяти при seq 224: 0.1–0.3 нат; **ближайший приоритет — униграммный разрыв 0.91 нат**, не память.

## 5. Агент E — ствол/aux

- **Branch-loss тождество**: B = 1.75·Var(δ) + 0.25·δ̄² (доказано + mini). Гессиан: якорь в 7× слабее на общую моду, чем пары на разности. Якорь — «детектор изменения шкалы», не «якорь здоровой шкалы» (насыщение сигнала на log(1000)≈6.9; самореферентен, пере-базируется на resume).
- **RMS+только отношения НЕ убивает класс 2970**: gauge-свобода, dL/ds≈0 (mini). Нужен фиксированный gauge: r*_{i,type} (полоса ±1 декада) или эталон на ‖h_l‖. При этом RMS-статистика правильная: устраняет слепую зону «застревание на однородных нормах» (∂Var/∂x=0 при ‖x‖≡n) и чинит обусловленность.
- **Пары с mirror доминируют** (94%/88%): v_mirror на 1–2 порядка меньше → лосс балансирует дисперсию норм, а не амплитуды (RMS 2.8 vs 13.4 = 4.8×).
- **Аудит aux**: gate_repulse=−3.43≈−ln32 (насыщен, дубликат balance); nuc=0 инертен + градиент радиальный; bridge_conn=6.15 vs chance ln(446)=6.10 — на полу случайного; **usef=0.502 — структурный артефакт медианного центрирования** (mean≡0.5 при любом разбросе); alpha_novelty применяется дважды; signal_ent 1.29/1.609 (80% max).
- **Kill-switch**: дешёвая версия — round-robin grad_geometry (proj_i = cos(g_i,g_CE)·‖g_i‖/‖g_CE‖) + триггер Шмитта с dwell; блок-абляции только на форк-прогоне (нет rollback).

## 6. Агент F — эффективность и данные

- **Доминирующий расход — ТРИ полных backward** (LossBalancer: CE / aux_total / bypass, training_control.py:358,397,437) — единственный объяснимый кодом множитель ~2.5–3×. Рычаг №1: свести к 1 → **1.5–1.9×**.
- Прочее: forward+recompute ~20–25%; ~288 data-dependent if (_chk) и сотни .item()-синков на forward; банк — двойной Python-цикл с синком на элемент (448/forward).
- **AMP**: 1.1–1.4× время, 0.65–0.85× память (не 2×); B10b закрыт (concept_layer.py:235), но смешанные dtype-пути проверить. **torch.compile — не стоит** (≈288+ graph break/forward, списковое состояние кэшей, suppress_errors маскирует).
- **Данные**: эпоха 2.9M шагов; 7315 = 0.25%; бюджет ~15ч остатка ≈ +3.1M токенов. Ротация 250 шагов = 30 секунд обучения на жанр (CE не успевает выучить даже юниграмму жанра) → для CE-стабильности рекомендован chunk **1000–2000 шагов**, 250 — ограниченный A/B для novelty-цепочки.
- Ошибка печати токенов/чанка (27.5k устарело) — исправлена.
