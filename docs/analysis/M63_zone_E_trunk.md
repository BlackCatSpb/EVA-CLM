## 2. Математика

### 2.1 Текущий branch-loss: тождество, гессиан, равновесие

`ℓ_i = log v_i`, `v_i = Var_t(‖x_i(t)‖) + ε`, `r = log ref`, `w_a = 0.5`:

```
L = (1/(6N)) Σ_l [ Σ_{i<j} (ℓ_i−ℓ_j)² + w_a Σ_i (ℓ_i−r)² ]
```

**[формула] Тождество.** `Σ_{i<j}(δ_i−δ_j)² = 9·Var_pop(δ)`, `Σδ_i² = 3·Var_pop(δ)+3δ̄²` ⇒

```
B = L = 1.75·Var_pop(δ) + 0.25·δ̄²
```

**[mini] проверка:** L0: v=(19.6, 107, 0.345), ref=42.287 → B = 10.13+0.60 = **10.73**; код даёт 10.735 ✓.

**[формула] Гессиан по ℓ:** пара-часть `6I−2J`, якорь `I`, итого `H = 7I−2J` (/6N). Вдоль общего сдвига — `1/(6N)`, вдоль разностей — `7/(6N)`. **Якорь в 7 раз слабее на общую моду, чем пары на разности** — причина, почему равномерный дрейф требует больших B.

**[формула] Равновесие:** `v_c = v_b = v_m = ref`. Ключевое: **равновесие фиксирует дисперсию норм, а не масштаб** (добавление постоянного вектора к ветке не меняет Var_t(‖x‖) в первом порядке). Первая слепая зона статистики.

**[формула] Стационарная точка при однородных нормах:** если `‖x_i(t)‖ ≡ n`, то `dv/dx = 0` при любом n, включая `1e16` — «застрявшее» состояние с большим лоссом и нулевым градиентом. Вторая слепая зона. RMS-статистика такой точки не имеет: `∂log r/∂x = x/Σ‖x‖² ≠ 0`.

**[формула] Обусловленность:** `∂log v/∂x_t = (2/N)·(n_t−n̄)/v·x̂_t` — коэффициент `1/v` взрывается на почти однородных ветках (у mirror [mini] `v=0.35`); `∂log r/∂x_t = x_t/Σ‖x_t‖²` — гладко.

### 2.2 Какие пары доминируют

[mini, 2 слоя, init, train]:

| Слой | RMS c/b/m | Var c/b/m | pair cb | pair cm | pair bm | Σpair/6 | anchor/6 |
|---|---|---|---|---|---|---|---|
| L0 | 13.36 / 41.61 / 2.76 | 19.6 / 107 / 0.345 | 2.88 | **16.32** | **32.92** | 8.69 | 2.05 |
| L1 | 12.05 / 5.11 / 4.54 | 26.0 / 4.7 / 0.472 | 2.93 | **16.08** | 5.28 | 4.05 | 2.11 |

Доминируют пары **с mirror** (L0: 49.2/52.1 = 94%; L1: 21.4/24.3 = 88%): `v_m` на 1–2 порядка меньше (mirror-выход самый однородный), `log v` для него самое отрицательное. Лосс балансирует **дисперсию норм**, а не амплитуды (RMS 2.8 против 13.4 = 4.8×). Production: ref=6875 — среднее трёх *дисперсий*; при σ/μ≈0.3 типичные нормы ~250, т.е. 1–2 декады до `branch_cap=1e4`.

**Оценка B=28–215.** Из тождества: при δ̄≈0 `Var=16–123` → разброс дисперсий `e^{±4..±11}`; при `Var≈0` `|δ̄|=2√B=10.6–29.3` → средняя дисперсия в `4e4–5e12` раз выше ref. Волатильность 28↔215 указывает скорее на пары (форма веток шумит), но однозначно из лог-скаляра не идентифицируется — нужна per-branch телеметрия.

### 2.3 Предложение: RMS + только отношения — вывод

`r_i = sqrt(mean_t‖x_i(t)‖²)` (L2-вклад ветки в поток):

```
L' = (1/(3N)) Σ_l Σ_{i<j} (log r_i − log r_j)²
```

**[формула] Градиент.** `∂log r_i/∂θ_i = x_iᵀ(∂x_i/∂θ)/Σ_t‖x_i‖²` — однороден степени 0, `O(1)` при любом масштабе (для Adam сила не затухает). Но при `x_i → s·x_i` (все i) `L'` инвариантен: `dL'/ds ≡ 0` — градиент **строго ортогонален масштабной моде**. [mini] конечная разность: `L'=12.700`, `dL'/ds = −2.9e-3` при `‖∇L'‖=65` (численный шум).

**[mini] Замена статистики.** Гомогенизация conv при том же RMS (r=13.358): `Var 19.6 → 8.4e-12`; `Σpair(var) 52.1 → 1273.8`, `Σpair(rms) 11.15 → 11.13`. То есть старая пара-часть — штраф за неоднородность норм (25× скачок при неизменном масштабе), новая — нет. Аргумент **за** RMS независимо от якоря.

### 2.4 Умирает ли класс 2970 «по построению»?

**Нет.** Три факта:

1. **Симметрия.** `L'` инвариантен к `x_i → s·x_i` — класс «равномерный разгон ×10/слой» неотличим от покоя (то же для пар в текущем лоссе, `test_m51:80-84`). Доказательство «смерти по построению» через лосс невозможно: это gauge-свобода.
2. **Fuse/caps убирают катастрофу, но не дрейф.** M50-дедлок архитектурно исключён (overflow-safe `_ln`/`final_norm`). Но cap не регулятор масштаба: [mini, float64] радиальная производная `_stream_cap` при `|x| ≥ cap` = 0 (измерено ~1e-14); тангенциальная ~`cap/m`. При `m=1e6` CE-градиент в ветку ×1e-3, при `1e16` — ×1e-12: ветка «умирает» (starvation), поток цел. Это M52a-урок «мёртвый base в нормированном пути».
3. **Якорь — единственный канал с ненулевой проекцией на масштаб.** [mini] при равномерном росте ×10/×100/×1e4/×1e8: `L_rel` 12.7–12.6 (инвариант), `L_rms` 2.14–2.06, `L_anchored` растёт 8.4 → 9.3 → 31 → 154 → 718, ‖∇_θ‖ 47.8 → 48 → 72 → 156 → 342 (лог-рост — то, что нужно Adam). Убрать якорь = оставить моду без возвращающей силы.

**[формула] Слепота EMA-якоря по времени.** `ref ← 0.999·ref + 0.001·mean(v)`: для разового скачка в s раз якорь видит `log(s²/0.001) = 2log s + 6.9` — сигнал **насыщается** на `log(1000)≈6.9` (вклад в B ≈ 0.25·47.6 ≈ 12 на слой). Для устойчивого роста с шагом g — `log(g²)+6.9`. Медленный дрейф (>~1000 вызовов) разрешён by design. Плюс ref самореферентен: засев — первое наблюдение ([mini] ref=42.3 на шаге 1), персистится (M58c), после resume пере-базируется.

### 2.5 Что теряется/что нужно сохранить

- **Нужен явный масштабный канал.** Из-за pre-LN CE-градиент по общей амплитуде инъекций — второго порядка: при `s→∞` `LN(h)` перестаёт зависеть от s, `∂CE/∂log s → 0` (как `O(1/s)`). Полагаться на CE в контроле масштаба нельзя — M52a-урок.
- **Что теряется при «только отношениях»:** (i) общая мода — свободный дрейф до cap'а и starvation; (ii) разрешённый медленный рост — при фиксированном эталоне пропадает; (iii) ref как «память здоровья» при resume.
- **Рекомендуемая форма (gauge вместо EMA):**

```
L_branch = (1/(3N)) Σ_l Σ_{i<j} (log r_i − log r_j)²
         + (w_g/(3N)) Σ_l Σ_i (log r_i − log r*_{i,type})²
```

где `r*` — **фиксированный** эталон per-branch-type (по первым K здоровым шагам, полоса `[r*/10, 10 r*]`), либо — предпочтительно — эталон на **RMS потока** `r*_l = ‖h_l‖` (поток ограничен fuse'ом 1e3). Вариант B: явный learnable `log_scale_branch` на ветку (сейчас его нет) — масштаб становится параметром с прямым градиентом.

## 3. Количественные оценки

1. **`head_wall=3541`.** `wall = 1e-3·mean(relu(|u|−6)²)` → `mean=3.54e6`. Если насыщены все элементы: `|u| ≈ 6+√3.54e6 = 1888`; если 10%: `|u|≈5958`; если 1%: `|u|≈1.9e4`. Согласуется с `sat=1.0`. CE-градиент сигмоидного пути при `|u|=1888` мёртв; градиент стенки `2e-3(|u|−6) ≈ 3.8` — единственный живой канал. Но 3541 — крупнейший aux-терм: в align-режиме он забирает aux-бюджет на параметрах головы в спайке. (Агент A: числа несовместимы с геометрией текущей головы — приоритет live-захват.)
2. **`gate_repulse = −3.43`** = `−H(softmax(usage))`, `ln32=3.466`. Дефицит 0.036 → распределение в пределах 1% от равномерного; градиент `p_i−1/G` ≈ 1e-3. Терм **насыщен в своём оптимуме** и дублирует `balance`.
3. **`bridge_conn = 6.15`.** InfoNCE при B=2, L=224: `Nq=446`, chance = `ln 446 = 6.10`. 6.15 — **на полу случайного угадывания**. Probe отцеплен от ствола (`stack.py:603`), readiness при `sat≈0` ≈ 0 → инъекция bridge фактически выключена. Маргинальная ценность ≈ 0 при стоимости InfoNCE `O(Nq²·n_layers)`.
4. **`usef = 0.502` — не признак смерти.** `usefulness = σ((logits−median)/temp)` — медиана центрирует → `mean(u) ≈ 0.5` **тождественно**. `reinforce = MSE(u, gate)` 0.10 при `u` std≈0.32 — u **не** схлопнут. Алайвность мерить `std_G(u)` или ранговой корреляцией с `‖∂CE/∂mlp_out‖`.
5. **`nuc = 0` — инертен by construction.** `sr = clamp(‖W‖_F²/σ̂max², 1, rank)`; у гауссовой W `sr ≈ rank` → penalty = 0 → градиент 0. Хуже: при penalty > 0 `σ̂max` detached ⇒ `∂penalty/∂W = −2W/(σ̂max²·rank)` — **чисто радиальный** вектор, а stable rank `W→sW` инвариантен. Терм толкает рост нормы, а не восстановление ранга.
6. **`decorr=0.12`, `diversity=0.07–0.10`, `signal_ent=−1.29`, `alpha_novelty=−0.0005`, `div=−0.0196`.** `decorr`: среднее `cos²` по 10 парам → |cos|≈0.35. `signal_ent`: H=1.29 из ln5=1.609 (80%). `alpha_novelty`: `var_G(α)=5e-4` → std 0.022 (2%). `div`: сумма дисперсий σ(log_scale) ≈ 0.02 → std≈0.1. Итог: **эксперты зеркала почти не различаются** ни по α, ни по log_scale, ни по гейту.
7. **Стоимость.** `bridge_conn`: `Nq²` на слой (446²×24 ≈ 4.8e6 пар/шаг) — самый дорогой; `decorr` 10 пар; `diversity` corr 32×32; `nuc` 4 степенных итерации; `gradalign` — бесплатный hook, но добавляет путь в backward.

## 7. Kill-switch: дизайн

**Что уже есть.** В align-режиме балансер — непрерывный молчаливый kill-switch: `p.grad += gau·1[gce·gau>0]·min(1,‖gce‖/‖gau‖)`. Терм с ортогональным/противонаправленным CE-градиентом получает ~0; при `gce=0` aux не проходит вовсе. Отсюда: (i) «вредные» термы уже гасятся по параметрам; (ii) ценность терма по значению лосса измерить нельзя — только по градиентной проекции; (iii) удаление терма меняет направление остальных (сумма нормируется) — абляция неаддитивна.

**Инструмент A (дёшево, непрерывно).** Round-robin: каждые `log_interval` брать 2–3 терма и считать `grad_geometry` — `cos` и `‖g_i‖/‖g_CE‖`; полное покрытие за ~8–12 лог-шагов при стоимости 1 retained-backward (вместо 8 сразу — причина удаления в M48). Метрика: `proj_i = cos_i·‖g_i‖/‖g_CE‖`.

**Инструмент B (блок-абляция).** Отключить терм на `W = 2·eval_interval`, измерить дрейф целевой метрики (EMA до/после) и CE; контроль — соседнее окно. `Var(Δy) ≈ 2σ_y²(1−ρ^W)/(1−ρ)`; для val мощность низкая — использовать train-метрики.

**Правило (Шмитт + dwell):**
```
off_i: (proj_i < ε_off K подряд) ИЛИ (y_i в аналитическом оптимуме) ИЛИ (y_i в полосе)
on_i:  (proj_i > ε_on) ИЛИ (y_i вышел из полосы) ИЛИ (val CE вырос > δ после off)
ε_on > 3·ε_off;  dwell ≥ 2·eval_interval;  бюджет ≤ 4 переключения/терм/прогон
```
«Аналитический оптимум»: `nuc=0`, `gate_repulse ≥ lnG−0.02`, `lbg_diversity=0` — бесплатные кандидаты на отключение.

**Целевые метрики:** branch → per-branch r_i; gate_repulse/balance → H/HHI usage; reinforce → std_G(u); decorr → mean cos²; diversity → MSE(corr,I); gradalign → ранг-корр; signal_ent → H(w); alpha_novelty → std_G(α); div → var(σ(log_scale)); nuc → stable rank; wall → квантиль |u|; bridge_conn → InfoNCE минус chance-floor.

## 8. Вердикт

1. **RMS-норм + только отношения — переформулировать.** Статистика правильная (устраняет F3, чинит обусловленность); но «только отношения» не убивает класс 2970 — gauge-свобода. Нужен явный gauge: фиксированный `r*` или эталон на `‖h_l‖`.
2. **Аудит aux — частично делать.** Первые шаги: логировать невидимые термы и per-branch RMS; удалить `gate_repulse` и `nuc`; починить метрику `usef` (std вместо mean); признать `bridge_conn` на chance-floor; зафиксировать on/off-семантику весов в доках/тестах (T13).
3. **Kill-switch — дешёвую версию** (round-robin grad_geometry + Шмитт), без блок-абляций на живом прогоне (нет rollback); блок-абляции — на форк-прогоне от best.pt.
4. **Тесты — делать** T1–T13.

**Неопределённости:** разбиение branch=28–215 на пары/якорь из лог-скаляра не идентифицируется; вывод о chance-floor bridge зависит от Nq и доли повторов; production-шкала веток оценена через ref=6875; мощность kill-switch-оценки не считалась; эффект удаления gate_repulse/nuc на CE не измерялся ни разу.
