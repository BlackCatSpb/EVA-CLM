# Журнал коллективных выводов

Назначение: **единственный источник коллективных выводов** мультиагентных
обсуждений архитектуры EVA-CLM. Используется для будущих правок кода,
конфигов и документации. Живое обсуждение — в `AGENT_BOARD.md`; сюда попадает
**только то, что сошлось** (или осознанно открыто) после проверки.

Правила ведения:
- запись = тема → вердикт (закрыто/открыто) → выводы с доказательствами →
  открытые вопросы → действия (для правок/экспериментов);
- если вывод меняется новым обсуждением — правка записи с датой и ссылкой на
  обсуждение (без переписывания истории: старый текст в разделе «Архив»);
- цитаты/числа — только проверенные (из лога, analyze-отчётов, кода).
