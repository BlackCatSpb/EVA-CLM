EVA-CLM — пакет для внешнего анализа: генерация на чекпоинте 13640

Дата сборки: 2026-09-22, ~19:00 MSK. Назначение: передать внешним агентам

полный контекст + сырые результаты генерации + диагностику, объясняющую её

качество, для независимого разбора и рекомендаций.

0. Резюме для агентов (TL;DR)

  • Модель EVA-CLM (183.14M параметров, 24 слоя, D=2560, словарь 65536) обучена

~13.6k шагов; best val (CE, нат/токен) = 7.9260 (на hold-out).

  • Генерация в smart-режиме на этом чекпоинте даёт словесный салат

(служебные слова + пунктуация, без структуры) — полный транскрипт в §3.

  • Диагностика: маркер BIAS-DECOMP (доля позиций, где argmax полных логитов

совпадает с argmax одного лишь token_bias) прошёл путь 0% → 100% между

шагами 3080 и 10560. То есть контекст перестал влиять на top-1 выбор модели:

предсказания стали определяться униграм-биасом.

  • Гипотеза: модель сидит на потолке своего бит-независимого семейства головы

(независимый замер: bigram-потолок семейства 7.96 нат, при этом полная

биграммная модель даёт 3.73, униграмма 4.72). На этом потолке при слабом

контексте оптимально хеджировать (уплощаться и опираться на приор) —

CE улучшается, argmax-структура деградирует. Механизм уплощения:

log_temp (побитная температура кодового чтения) вырос 0.106 → 0.281 → 0.310.

  • Решающий тест уже запущен: в текущий прогон включён парный канал головы

(rank-16 Ising-поправка; по замеру закрывает 66.7% разрыва бит-независимости).

Предсказание: если контекст снова начнёт выигрывать argmax — маркер пойдёт к 0%,

val ниже 7.9; если нет — бутылочное горлышко глубже семейства головы.

1. Модель и конфигурация

1.1 Архитектура (кратко)

Ствол: 24 слоя, каждый — conv-ветвь + VSA-память (4 τ-шкалы: 8/32/128/512, обучаемая

лестница) + bind (trajectory_spiral, K=32) + спектральная ветвь + grouped MLP

(32 группы, expand 4) + «зеркало» (GroupedCognitiveMirror: эксперты, приватная

память, K-space предсказание). Когнитивные надстройки: logit_cache (многошкальный

кэш 8..8192), memory_bank, unified_concept_layer (UCL), intent bridge (stencil),

explicit_reasoning (adaptive), meta_trust, bridge (SemanticBridge, 1.38M параметров).

Голова (SigmoidCodedHead, head_mode=sigmoid_coded, normalize=True):

logits_v = u·c_v + token_bias + (фантом-канал) + (pair-канал), где u — 64-битное

кодовое состояние (sigmoid от z/T + bit_bias + bus_bias), c_v ∈ {0,1}^64 — коды

словаря (ровно 6 активных битов на токен, twin_free-упаковка). Семейство

бит-независимо (без взаимодействий битов) — это ключевое ограничение (§4.4).

Чтение: на 3080 контекст выигрывал argmax на всех позициях (модель

4.2 log_temp: что это (код)

log_temp — побитная температура кодового чтения (не словарная):

# core/embedding.py, SigmoidCodedHead._gates
h_g = h.reshape(B, L, self.K, -1)
z   = (h_g * self.readout.unsqueeze(0).unsqueeze(0)).sum(dim=-1)   # (B,L,64)
T   = torch.exp(self.log_temp)                                     # (64,)
T   = T + (T.clamp(0.1, 10.0) - T).detach()   # ST-кламп: forward [0.1,10], backward identity
z_data = z / T                                 # «мягкость» битов
zt = z_data + self.bit_bias  (+ bus_bias)

Рост log_temp 0.106 → 0.310 ⇒ T 1.11 → 1.36 ⇒ сигмоид-биты мягче ⇒ u·c_v

(сумма 6 активных битов) выравнивается по словарю ⇒ контекстный вклад теряет

различительную силу ⇒ argmax падает на bias. Старое значение ref: +0.0188 на

шаге 1398.

4.5 Гипотеза причинной цепочки (проверяемая)

1. P0-1 (F2) фикс: кламп τ_s (fp32-предохранитель скана) связывает на мелких

слоях: τ_s 0.33→1.0, decay 0.048→0.37 ⇒ VSA-память мелких слоёв стала жить

~×8 дольше ⇒ рост норм (h_norm 160 → 500–3600).

2. Рост норм ⇒ периодические сатурации u (u_max ~330–360) ⇒ CE-градиент через

софтмакс в насыщении ≈ 0.

3. Модель учится уплощаться (log_temp ↑) — чтобы сохранить градиент/калибровку.

4. Мягчение битов ⇒ контекст слабеет ⇒ хеджирование на униграм-приор ещё

выгоднее (петля).

5. Наблюдаемые симптомы: BIAS-DECOMP 100%, H≈6–7 нат, генерация-салат, val

улучшается (калибровка), argmax-структура деградирует.

Альтернативные объяснения (для агентов): (a) log_temp рос независимо от

сатураций (просто выученная калибровка); (b) переход 0%→100% связан с другими

событиями того же окна (открытие logit_cache на 3520, разморозка глубины до 24,

рампа зрелости, батч аудит-фиксов); (c) хеджирование — вообще правильный ответ

(контекст реально неинформативен на этом объёме данных), и генерация появится

только при val ниже униграммы (4.72).

5.5 Варианты вмешательства (меню для агентов)

1. Pair-канал (уже в прогоне) — расширение семейства; ждём un-hedging.

2. Границы log_temp — мягкий штраф к 0 / кламп (сейчас ST-кламп [0.1,10]

слишком широк; ref +0.019). Риск: заморозка калибровки (в коде есть комментарий,

что старый кламп «замораживал log_temp»).

3. Масштаб readout — усилить контекстный вклад (readout сейчас std 0.168,

readout_lr_mult=1.0).

4. Расширение семейства сильнее rank-16 (полная Ising/больший rank, морфокоды

P1-3) — против потолка +4.2 нат.

5. Ослабление τ-клампа (vsa_decay_floor_k 2.0 → 1.5: безопасный пол 0.75,

запас до ln(FLT_MAX) сохраняется) — уберёт источник роста норм, но сдвинет режим.

6. Только обучение — если контекст реально неинформативен на 13k шагов,

генерация появится при val < 4.72 (уровень униграммы).

5.6 Таймлайн изменений (для атрибуции)

  • Резюм 7040→10560: батч аудита F1–F6 + P0-1…P0-6 + гигиена + живой eval-_lac

8. Словарь (для агентов)

  • val — CE на hold-out (нат/токен), main-метрика.
  • BIAS-DECOMP — доля позиций, где argmax полных логитов = argmax одного

token_bias (униграм-приора).

  • log_temp — побитная (64 бита) температура кодового чтения; T=exp(log_temp),

ST-кламп [0.1,10].

  • τ_s-кламп (P0-1/F2) — предохранитель fp32-скана VSA: τ_s ≥ 0.5·k; на мелких

слоях связывает (τ_s 0.33→1.0).

  • PoB — семейство головы: q(v|u) ∝ exp(Σ_k c_vk u_k) (бит-независимое).
  • Сатурация — |u| > ~12 (sat=1.0 при u_max ~330–360); CE-градиент ≈ 0.
  • Зеркало (mirror) — модуль per-layer предсказания в K-пространстве с

экспертами и приватной памятью.

  • Леджер — парные измерения ΔCE при выключении регулятора (P3-1).
